## 10. 验证门槛（框架统一，不因策略降低）

想法来源与证据链记在想法登记簿（`research/ideas.jsonl`），本规格须写明对应的想法 id；统计检验口径见 `docs/RESEARCH_LAB.md`。


| 门槛 | 要求 |
| --- | --- |
| G0 | 前视偏差检查通过 |
| G1 | 组合回测（主证据）≥ 100 笔；30–99 笔最多判“证据不足”，< 30 笔不做检验；期望 R 的 Bootstrap 95% 区间下限 > 0、按周汇总的 Bootstrap 下限 > 0。上线判定用 `verdict --idea <id>`（示例值） |
| G2 | 最后一段时间不参与调参：回测**之前**用 `lab idea holdout --id <id> --start <日期>` 登记（只能登记一次，登记时间要早于组合回测开始）；起点必须落在回测时间段之内；按入场时间归属，跨边界持仓不算；样本外期望 R > 0 且 ≥ 10 笔；样本外段占时间段的**目标约 30%，程序接受 20%–50%**（示例值，见下方“G2 门槛变更”）；未登记 → 证据不足 |
| G3 | 分段一致性：至少 60% 的时间段期望 R > 0。注意这是同一批结果按时间切段，不是“训练 → 冻结 → 测试”的滚动验证；后者需按段分别选参、冻结、测试（框架未自动化） |
| G4 | 参数稳健（见上）；按尝试次数折扣后 Deflated Sharpe > 0.95、PBO < 0.5（示例值）。两项都在 `research verdict` 里判定：PBO 来自组合回测里至少 2 个实际不同的候选方案（`portfolio --all --trials …`），只用样本外起点之前的开发区间（v2.10），算不出 → 证据不足；尝试次数取登记簿与候选数中较大者 |
| G5 | 策略声明的全部必需压力方案（见下方“研究要求”）期望 R 仍 > 0；没跑或失败 → 证据不足；零交易 → 不通过。未实现的情景（见 `docs/RESEARCH_LAB.md`）要在结论里写明 |
| G6 | 极端情景（历史最大单日跌幅、跳空穿过止损） |
| G7 | 代码一致性：模拟运行信号与回测逐条一致 |
| G8 | 模拟运行 ≥ 4 周且 ≥ 20 笔 |
| G9 | 小额实盘（≤ 1,000 USD）≥ 8 周，须你书面授权 |

**G2 门槛变更（v2.7 → v2.8 记录，示例值）**：v2.6 及以前写的是“最后 30%”，程序没有检查比例。v2.7 起程序检查比例，下限设为 20%，这**放宽**了文字上的 30%，理由：
- 起点必须在回测之前登记，而组合回测的终点常常是“到最新数据”（开放的时间段），登记时无法精确算出 30%；
- 按入场时间归属后，样本外段末尾还在持仓的交易不能平仓前计入，实际可用时间比日历时间略短。
v2.8 同时加了上限 50%（样本内至少一半），并按回测时间段而不是交易首尾计算比例。目标仍是约 30%；改动这两个数要写进策略规格和研究记录，不能在看到结果之后改。

**研究要求（随策略而定）**：在策略类里声明 `research_stress`（可选 `cost2x`、`delay1`、`stopslip`；默认三项全要）与 `research_stop_slip`（示例值 0.002）。框架最低要求 `cost2x`、`stopslip`，不能去掉（v2.9）；去掉 `delay1` 要在 `research_stress_waivers` 里写理由，例如 `{"delay1": "只用市价单入场，信号到下单没有排队等待"}`。
